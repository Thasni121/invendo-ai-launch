# Finish Invendo AI Academy Website

## Goal
Complete the existing Invendo project without replacing its content or official assets, then verify it as a launch-ready corporate training website.

## Implementation
1. **Wire the complete site**
   - Replace the placeholder home screen with the existing Invendo home page.
   - Add route files for every required page, plus the existing privacy and terms pages.
   - Wrap all pages in the existing shared header and footer.
   - Ensure every navigation and internal link points to a real page.

2. **Polish the corporate presentation**
   - Finish the semantic color, typography, spacing, image, card, button, focus, and motion styles already referenced by the Invendo components.
   - Refine the desktop navigation into a clear, usable structure and complete the accessible mobile menu.
   - Preserve the official logo proportions and use all 19 supplied photographs with their documented captions and descriptions.
   - Add the requested home FAQ and fill small documented content gaps such as Corporate Companies, training formats, technology areas, and case-study key insights.

3. **Complete conversion features**
   - Strengthen field labeling, error announcements, required-state handling, and submission feedback in the corporate enquiry form.
   - Keep secure server-side validation, honeypot spam protection, and database submission.
   - Complete the AI Readiness Assessment with all requested inputs, explicit assessment action, useful recommendations, and a path into the corporate enquiry flow.

4. **Finish launch essentials**
   - Replace placeholder global metadata and favicon references.
   - Add unique titles, descriptions, Open Graph, Twitter, canonical metadata, and appropriate structured data for each page.
   - Add XML sitemap, sitemap footer link, robots sitemap declaration, and a branded not-found page.
   - Remove the obsolete placeholder favicon and any remaining placeholder content.

5. **Verify the finished experience**
   - Run focused static checks and rely on the platform’s automatic build/type validation after edits.
   - Test every required URL, header/footer link, CTA, form validation, assessment interaction, logo, and image in the live preview.
   - Inspect representative desktop and mobile layouts, browser console errors, page metadata, and broken image/link results; fix all discovered issues.

## Content safeguards
- Keep project clients / technology engagements, training experience, and industry partners visibly separate.
- Preserve proposed-program labels and all documented names, qualifications, testimonials, and figures.
- Do not invent clients, results, awards, testimonials, or credentials.
- Do not use generic replacement photography or “Enroll Now.”
